# 최종보고서 작성용 메모

## 프로젝트 배경
- 보안 로그는 시스템 운영에서 중요한 정보이다.
- 하지만 사람이 모든 로그를 실시간으로 확인하기 어렵다.
- 따라서 AI 기반 분석을 통해 이상 징후를 탐지하고 시각화하는 시스템이 필요하다.

## 프로젝트 목표
- 로그 수집 및 저장 시스템 구현
- AI 기반 보안 이벤트 탐지
- 대시보드 기반 모니터링 환경 제공
- 클라우드 환경에서 실행 가능한 구조 설계

## 구현 내용
- 백엔드 API 서버 구현
- 백엔드 - Kafka - AI 서버로 비동기화 구조 설계
- MySQL 기반 로그 저장
- AI 분석 모듈 연동
- 대시보드 구현
- Docker 기반 실행 환경 구성

## 기대 효과
- 실시간 보안 이벤트 모니터링 가능
- 로그 분석 자동화
- 보안 이벤트 대응 시간 단축
- 클라우드 기반 확장 가능성 확보
